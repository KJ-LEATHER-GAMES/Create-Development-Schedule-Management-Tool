### Q9 ガントチャートの4仕様

| 仕様 | 表示単位 | 時間粒度 |
|---|---|---|
| 機種開発日程一覧 | 開発案件1件＝1行 | 月の上旬・中旬・下旬 |
| イベント一覧（日単位） | 開発案件×ステージ＝1行 | 1日 |
| イベント一覧（旬単位） | 開発案件×ステージ＝1行 | 月の上旬・中旬・下旬 |
| 単一機種の開発日程＆イベント一覧 | 案件／ステージに対応する表示 | **未確定** |

※ ガントの行単位は表示上の集約単位であり、Q4の「開催回別の保存単位」を変更しない。同日／同旬重複時の表現は未確定。

**判定：Met 1 / Not Met 6。** 質問数上限15問に達したため、本GrillMeはいったん停止し、自動延長しない。終了の最終判断はユーザーが行う。

## 3. 未決事項

### Now — EXIT達成に必要
1. 管理要否、適用要否、イベント進捗、未計画／中止／再開催／再計画等の定義・状態遷移。
2. 情報種別別の正本マッピング、入力経路、更新頻度、証跡参照ルール。
3. 管理担当者の主要業務シナリオ（新規登録・計画変更・再開催・進捗更新・エビデンス登録・整合確認）。
4. ダッシュボード絞り込み、期間の厳密な定義、重複マイルストーンの解釈、単一機種表示仕様。
5. 主要運用制約（想定件数、Excel利用環境、配布・権限・更新競合、保存・バックアップ）。
6. MVPの受入基準（正しい状態・誤り・合否を確認できるテストシナリオ）。

### Later — 詳細要件・設計で決定可能
- 列数／初期表示期間／日付移動UI、シート構成、数式・VBA・Power Query選択。
- 具体的ステータス表示の色・記号・レイアウト、重複時の視覚表現の実装。
- エビデンスリンク切れ検証の具体的な実装、計画変更履歴の高度化。
- Qlik Senseへの接続・データロード方式。

### Not Now
- 全機種・全イベント・全ファイルの実データ登録。
- 組織横断の既存承認ルールの変更。
- 高度な自動連携・通知・Qlik Senseアプリ実装。

## 4. Scope外として退避した論点

| 論点 | 区分 | 理由 |
|---|---|---|
| Excelシート／数式／VBA等の具体実装 | Later | 要件定義後の設計事項 |
| Qlik Senseの接続・アプリ開発 | 別GrillMe候補 | MVPの実装対象外 |
| 組織横断の承認制度変更 | Not Now | 本GrillMeの対象外 |

## 5. Question Limit到達時の判定

- **自動延長・自動終了しない。**
