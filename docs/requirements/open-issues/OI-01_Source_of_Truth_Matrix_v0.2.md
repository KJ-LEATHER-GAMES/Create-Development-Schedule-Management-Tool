## 2. 運用ルール（確認済み）

| 項目 | 確定事項 | 残る詳細 |
|---|---|---|
| Excel更新責任 | **管理担当者が一元更新**。内容の正確性に対する責任と入力作業責任は分離する | 情報種別ごとの内容責任者・判定権限者の特定 |
| 更新起点 | 変更情報を把握した際、管理担当者が手動で確認・反映する | 具体的な情報伝達経路／更新期限 |
| 定期照合 | **月1回**、正式情報源とExcelの整合性を確認。変更情報入手時は随時確認する | 各情報種別への適用方法、月次実施日 |
| 速報と正式値 | 議事録の速報等と部品表システムの正式値は区別し、速報で正式値を無条件に上書きしない | 画面上の表示優先順位 |
| エビデンス必須 | 管理要否・適用要否判定、正式日程変更、確定イベント計画・開催実績、開催ステータス変更 | 資料登録の技術的な強制方法 |
| エビデンス任意等 | 暫定・調整中情報は根拠を記録するが資料リンクの必須化は未決定。表示順・管理用メモは原則任意 | 暫定情報の根拠形式 |
| 不一致 | 不一致を**要確認**として記録し、正本と根拠の確認後にExcelを修正。確認日・対応結果・根拠を保持 | 不一致管理の列・入力画面・修正期限 |
| 資料参照 | Excel内の独立一覧で資料リンクと関連対象を管理。資料本体はExcelに埋め込まない | パス形式、改版追跡、アクセス権確認 |

### 不一致処理

1. 月次照合または随時確認で不一致を発見する。
2. 不一致を「要確認」として記録する。
3. 情報種別に対応する正本・エビデンスを確認する。
4. 管理担当者がExcelの該当値を修正する。
5. 確認日、対応結果、根拠を記録する。

※Excelが正本である項目を外部情報だけで自動上書きしない。
